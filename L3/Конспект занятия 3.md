## 2️⃣ Теория: что такое метод двух указателей (10 минут)

### Определение (простыми словами)

**Метод двух указателей** — это приём, при котором мы:

- используем **два индекса** в массиве / строке;
    
- двигаем их по определённым правилам;
    
- за один проход решаем задачу.

---

#### 🔹 3. Сравнение элементов

- текущий и следующий;

```
def merge_sorted(arr1, arr2):

    while p1 < len(arr1) or p2 < len(arr2):
```

### Two sum - two pointers

```
def two_sum_less(arr, target):
    arr.sort()
    
    nearest_sum = -1
    
    left = 0
    right = len(arr) - 1

    while left < right:
        if arr[left] + arr[right] < target:
            nearest_sum = max(nearest_sum, arr[left] + arr[right])
            left += 1
        else:
            right -= 1
    return nearest_sum
```

```Problem

283 Move Zeroes

Дан целочисленный массив nums, переместите все 0 в его конец, сохраняя относительный порядок ненулевых элементов.

Обратите внимание, что вы должны сделать это на месте, не создавая копию массива.

Example 1:
Input: nums = [0,1,0,3,12]
Output: [1,3,12,0,0]

Example 2:
Input: nums = [0]
Output: [0]

```

```Solution

# Naive (new array) - O(N)/O(N) !!! НЕ ПОДОЙДЕТ ПО УСЛОВИЮ !!! 
def moveZeroes(self, nums: List[int]) -> None:
	"""
	Do not return anything, modify nums in-place instead.
	"""
	new_arr = []
	for num in nums:
		if num != 0:
			new_arr.append(num)
	return new_arr

# Two-pointers - O(N)/O(1)
def moveZeroes(self, nums: List[int]) -> None:
	"""
	Do not return anything, modify nums in-place instead.
	"""

	left = 0
	for right in range(len(nums)):
		if nums[right] != 0:
			nums[left], nums[right] = nums[right], nums[left]
			left += 1

```

```Problem
27 Remove Element

Дан целочисленный массив nums и целое значение val, удалите все вхождения val в nums на месте. Порядок элементов может быть изменен. Затем верните количество элементов в nums, которые не равны val.

Учтите, что количество элементов в nums, которые не равны val, равно k, чтобы их приняли, вам нужно выполнить следующие действия:

Измените массив nums таким образом, чтобы первые k элементов в nums содержали элементы, которые не равны val. Остальные элементы nums не важны, так же как и размер nums.
Верните k.

Example 1:
Input: nums = [3,2,2,3], val = 3
Output: 2, nums = [2,2,_,_]
Explanation: Ваша функция должна вернуть значение k = 2, при этом первые два элемента nums должны быть равны 2.
Не имеет значения, что вы оставляете за пределами возвращаемого значения k (следовательно, это символы подчеркивания).

Example 2:
Input: nums = [0,1,2,2,3,0,4,2], val = 2
Output: 5, nums = [0,1,4,0,3,_,_,_]
Explanation: Ваша функция должна вернуть значение k = 5, при этом первые пять элементов nums должны содержать значения 0, 0, 1, 3 и 4.
Обратите внимание, что эти пять элементов могут быть возвращены в любом порядке.
Не имеет значения, что вы оставляете после возвращаемого значения k (следовательно, это символы подчеркивания).

```

```Solution

# Two-pointers - O(N)/O(1)
def removeElement(self, nums: List[int], val: int) -> int:
	index = 0
	for i in range(len(nums)):
		if nums[i] != val:
			nums[index] = nums[i]
			index += 1
	return index

```

```
class Solution:
    def isPalindrome(self, s: str) -> bool:
        
        # Initialize new str
        new_s = ''
        
        # Write each alphanumerical symbol (in lower register) into new string
        for c in s:
            if c.isalnum():
                new_s += c.lower()
        
        # Check if new_s is a palindrome
        return new_s == new_s[::-1]

# Operator ~ is the bitwise NOT operator. 
# It performs logical negation on a given number by flipping all of its bits: ~x == -x-1 , ~0 == -1, ~1 == -2 and etc.
class Solution:
    def isPalindrome(self, s: str) -> bool:
        s = [c.lower() for c in s if c.isalnum()]
        return all (s[i] == s[~i] for i in range(len(s)//2))

class Solution:
    def isPalindrome(self, s: str) -> bool:
        i, j = 0, len(s) - 1
        while i < j:
            while i < j and not s[i].isalnum(): i += 1
            while i < j and not s[j].isalnum(): j -= 1

            if s[i].lower() != s[j].lower(): return False
            i += 1
            j -= 1
```
