**719. Find K-th Smallest Pair Distance**  


```Problem

Расстояние между парой целых чисел a и b определяется как абсолютная разница между a и b.

Дан целочисленный массив nums и целое число k, верните k-е наименьшее расстояние между всеми парами nums[i] и nums[j], где 0 <= i < j < nums.len

Example 1:
Input: nums = [1,3,1], k = 1
Output: 0
Explanation: Вот все пары:
(1,3) -> 2
(1,1) -> 0
(3,1) -> 2
Тогда 1-я пара наименьших расстояний равна (1,1), а ее расстояние равно 0.

Example 2:
Input: nums = [1,1,1], k = 2
Output: 0

Example 3:
Input: nums = [1,6,1], k = 3
Output: 5


```

```

class Solution:
    def smallestDistancePair(self, numbers: List[int], k: int) -> int:
        numbers.sort()
        left, right = 0, numbers[-1] - numbers[0]
        
        while left < right:
            mid = (left + right) // 2
            if self.countPairsWithinDistance(numbers, mid) >= k:
                right = mid
            else:
                left = mid + 1
        
        return left

    def countPairsWithinDistance(self, numbers: List[int], targetDistance: int) -> int:
        count = left = 0
        for right in range(1, len(numbers)):
            while numbers[right] - numbers[left] > targetDistance:
                left += 1
            count += right - left
        return count

```

**33. Search in Rotated Sorted Array**  


```

Имеется отсортированный по возрастанию массив целых чисел nums с уникальными значениями.

Перед передачей в вашу функцию массив nums, возможно, был повёрнут влево на неизвестном индексе k (1 <= k < nums.length), так что полученный массив имеет вид [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]] (с отсчётом от нуля). Например, массив [0,1,2,4,5,6,7] мог быть повёрнут влево на 3 индекса и стать [4,5,6,7,0,1,2].

Учитывая массив nums после возможной ротации и целое число target, верните индекс target, если он присутствует в nums, или -1, если его нет в nums.

Вы должны написать алгоритм со сложностью по времени O(log n).

Example 1:
Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4

Example 2:
Input: nums = [4,5,6,7,0,1,2], target = 3
Output: -1

Example 3:
Input: nums = [1], target = 0
Output: -1

```

```

class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums)
        while left < right:
            mid = left + (right - left) // 2
            if nums[mid] < nums[0]:
                right = mid
            else:
                left = mid + 1
        pivot = left

        if target >= nums[0]:
            left, right = 0, pivot
        else:
            left, right = pivot, len(nums)
        
        while left < right:
            mid = left + (right - left) // 2
            if nums[mid] >= target:
                right = mid
            else:
                left = mid + 1
        return left if left < len(nums) and nums[left] == target else -1

```

### 3.2 Сложности операций (5 минут)

Проговорить и зафиксировать:

| Операция                  | Сложность |
| ------------------------- | --------- |
| Доступ по индексу         | O(1)      |
| Изменение элемента        | O(1)      |
| Вставка в конец           | O(1)*     |
| Вставка в начало/середину | O(n)      |
| Удаление                  | O(n)      |

* → подвести к амортизированной сложности.

---

### 3.3 Амортизированная сложность (5 минут)

На примере Python list:

- массив увеличивается не на 1 элемент, а **с запасом**;
    
- иногда происходит копирование всего массива;
    
- но в среднем `append` — O(1).
    

Важно:

> **Амортизированная сложность ≠ худший случай**

```
Example 3:
```


```
class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        
        # Sum of n unique elements [0; n]
        sum_needed = 0
        
        # Count needed sum
        for i in range(len(nums) + 1):
            sum_needed += i
        
        # Count difference between needed sum and actual sum
        for num in nums:
            sum_needed -= num
        
        # Value left in sum_needed is the missing number
        return sum_needed
```
