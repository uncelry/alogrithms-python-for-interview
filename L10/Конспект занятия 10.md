# ⏱ Структура занятия

## 1️⃣ Что такое жадный алгоритм и зачем он нужен (10 минут)

### 1.1 Определение

Жадный алгоритм:

* на каждом шаге делает **локально оптимальный выбор**;
* **не пересматривает прошлые решения**;
* надеется, что локальный оптимум приведёт к глобальному.

Примеры из жизни:

* давать сдачу самыми крупными монетами;
* выбирать ближайшее событие по времени окончания.

---

### 1.2 Почему greedy — опасен

Проговорить важную мысль:

> Greedy **не универсален**, его нельзя применять «по умолчанию»

Плавный переход:

* иногда greedy → оптимум;
* иногда greedy → тупик.

---

## 2️⃣ Признаки того, что greedy может подойти (15 минут)

### 2.1 Основные признаки (чек-лист)

Greedy часто подходит, если:

* требуется **максимум / минимум**;
* есть **отсортированные данные** или их можно отсортировать;
* выбор на текущем шаге **не ухудшает будущее**;
* решение можно строить **последовательно**;
* нет «возвратов» и зависимости от дальних решений.

Фраза-якорь:

> «Если оптимальный выбор сейчас не мешает оптимальности потом — возможен greedy»

---

### 2.2 Когда greedy НЕ подходит

Обязательно проговорить:

* задача требует учитывать будущие последствия;
* локально лучший шаг может сломать глобальное решение;
* есть зависимость от нескольких состояний.

Короткий контраст:

* greedy vs dynamic programming.

---

## 3️⃣ Как доказывать корректность greedy-алгоритма (15 минут)

Это **ключевая часть для собеседований**.

### 3.1 Что от вас хотят услышать интервьюеры

Не формальное доказательство, а:

* интуитивное обоснование;
* объяснение, почему жадный выбор безопасен.

---

### 3.2 Основные идеи доказательства

Разобрать устно:

1. **Exchange argument**
   Любое оптимальное решение можно преобразовать в жадное без ухудшения.
2. **Greedy stays ahead**
   На каждом шаге жадное решение не хуже любого другого.
3. **Оптимальная подструктура**
   После жадного выбора остаётся задача того же типа.

## 4️⃣ Практика: задачи с LeetCode (35–45 минут)

### 🧩 Задача 1 — демонстрация от преподавателя (10–15 мин)

**LeetCode 455. Assign Cookies**

Фокус:

* сортировка;
* жадный выбор;
* почему всегда выгодно давать минимально подходящее печенье.

Проговорить:

* инвариант;
* доказательство корректности.

```

Предположим, вы замечательный родитель и хотите угостить своих детей печеньем. Но вы должны давать каждому ребенку не более одного печенья.

У каждого ребенка i есть коэффициент жадности g[i], который представляет собой минимальный размер печенья, которым будет доволен ребенок; и у каждого печенья j есть размер s[j]. Если s[j] >= g[i], мы можем назначить cookie j ребенку i, и ребенок i будет доволен. Ваша цель - максимально увеличить количество довольных детей и вывести максимальное их количество.

Example 1:
Input: g = [1,2,3], s = [1,1]
Output: 1
Explanation: You have 3 children and 2 cookies. The greed factors of 3 children are 1, 2, 3. 
And even though you have 2 cookies, since their size is both 1, you could only make the child whose greed factor is 1 content.
You need to output 1.

Example 2:
Input: g = [1,2], s = [1,2,3]
Output: 2
Explanation: You have 2 children and 3 cookies. The greed factors of 2 children are 1, 2. 
You have 3 cookies and their sizes are big enough to gratify all of the children, 
You need to output 2.

```

```

class Solution:
    def findContentChildren(self, g: List[int], s: List[int]) -> int:
        g.sort()
        s.sort()
        content_children = 0
        cookie_index = 0
        while cookie_index < len(s) and content_children < len(g):
            if s[cookie_index] >= g[content_children]:
                content_children += 1
            cookie_index += 1
        return content_children


    def findContentChildren(self, g: List[int], s: List[int]) -> int:
        g.sort()
        s.sort()

        happy_children = 0

        g_idx = 0
        s_idx = 0

        while g_idx < len(g) and s_idx < len(s):
            if g[g_idx] <= s[s_idx]:
                happy_children += 1
                g_idx += 1
            s_idx += 1
        return happy_children

```

### 🧩 Задача 2 — совместно (15 мин)

**LeetCode 435. Non-overlapping Intervals**

Фокус:

* сортировка по правому концу;
* жадный выбор;
* минимизация удалений.

Обязательно:

* почему сортировка по началу не работает;
* intuition за сортировку по `end`.

```

Дан массив интервалов intervals, где intervals[i] = [starti, endi], верните минимальное количество интервалов, которые необходимо удалить, чтобы остальные интервалы не перекрывались.

Обратите внимание, что интервалы, которые соприкасаются только в одной точке, не перекрываются. Например, [1, 2] и [2, 3] не перекрываются.

Example 1:
Input: intervals = [[1,2],[2,3],[3,4],[1,3]]
Output: 1
Explanation: [1,3] can be removed and the rest of the intervals are non-overlapping.

Example 2:
Input: intervals = [[1,2],[1,2],[1,2]]
Output: 2
Explanation: You need to remove two [1,2] to make the rest of the intervals non-overlapping.

Example 3:
Input: intervals = [[1,2],[2,3]]
Output: 0
Explanation: You don't need to remove any of the intervals since they're already non-overlapping.

```

```

class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        intervals.sort(key=lambda x: (x[1], x[0]))

        last_interval = intervals[0]
        to_delete = 0

        for interval_idx in range(1, len(intervals)):
            curr_interval = intervals[interval_idx]
            if curr_interval[0] >= last_interval[1]:
                last_interval = curr_interval
                continue
            to_delete += 1
        return to_delete

```

### 🧩 Задача 3 — ученик (10–15 мин)

**LeetCode 121. Best Time to Buy and Sell Stock**

Фокус:

* локальный минимум;
* максимум разницы;
* жадный подход без DP.


```

Вам предоставляется массив цен, где prices[i] - это цена данной акции на i-й день.

Вы хотите максимизировать свою прибыль, выбрав один день для покупки одной акции и другой день в будущем для продажи этой акции.

Верните максимальную прибыль, которую вы можете получить от этой транзакции. Если вы не можете получить никакой прибыли, верните 0.

Example 1:
Input: prices = [7,1,5,3,6,4]
Output: 5
Explanation: Buy on day 2 (price = 1) and sell on day 5 (price = 6), profit = 6-1 = 5.
Note that buying on day 2 and selling on day 1 is not allowed because you must buy before you sell.

Example 2:
Input: prices = [7,6,4,3,1]
Output: 0
Explanation: In this case, no transactions are done and the max profit = 0.

```

```

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        max_profit = 0
        curr_price_bought = prices[0]

        for i in range(1, len(prices)):
            current_profit = prices[i] - curr_price_bought
            max_profit = max(max_profit, current_profit)
            if current_profit < 0:
                curr_price_bought = prices[i]
        return max_profit


```

* **LeetCode 122. Best Time to Buy and Sell Stock II**


```

Вам предоставляется целочисленный массив prices, где prices[i] - это цена данной акции на i-й день.

В каждый день вы можете принять решение о покупке и/или продаже акции. Вы можете владеть не более чем одной акцией в любое время. Однако вы можете продавать и покупать акции несколько раз в один и тот же день, гарантируя, что у вас никогда не будет более одной акции.

Найдите и верните максимальную прибыль, которой вы можете достичь.

Example 1:
Input: prices = [7,1,5,3,6,4]
Output: 7
Explanation: Buy on day 2 (price = 1) and sell on day 3 (price = 5), profit = 5-1 = 4.
Then buy on day 4 (price = 3) and sell on day 5 (price = 6), profit = 6-3 = 3.
Total profit is 4 + 3 = 7.

Example 2:
Input: prices = [1,2,3,4,5]
Output: 4
Explanation: Buy on day 1 (price = 1) and sell on day 5 (price = 5), profit = 5-1 = 4.
Total profit is 4.

Example 3:
Input: prices = [7,6,4,3,1]
Output: 0
Explanation: There is no way to make a positive profit, so we never buy the stock to achieve the maximum profit of 0.

```

```

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        total_profit = 0
        curr_price_bought = prices[0]

        for i in range(1, len(prices)):
            total_profit += max(prices[i] - curr_price_bought, 0)
            curr_price_bought = prices[i]

        return total_profit

```
